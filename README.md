# flask_rest_api_server
A simple REST API server built with the Flask framework.  

## Step 1- Install PIP
```bash
sudo apt install python3-pip   
```
## Step 2- Install Flask 
### virtual environment
```bash
sudo apt install python3.14-venv  
python3 -m venv venv  
source venv/bin/activate  
pip install flask
```
### System-wide
```bash
pip install flask --break-system-packages  
```
## Step 2- Create a Python file for the Flask application
```bash
app.py
```
## Step 3- After writing the program, run it
```bash
python3 app.py
```
